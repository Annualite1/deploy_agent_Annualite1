# Automated Project Bootstrapping and Process Management

## Project Description

This project automates the setup of a Student Attendance Tracker using a shell script called `setup_project.sh`.

The script creates the required project directory structure, generates all necessary files, allows users to update attendance threshold values, performs environment validation, and handles interruptions using signal trapping.

If the setup process is interrupted with `Ctrl+C`, the script automatically creates an archive of the project and removes the incomplete directory.

## Project Structure

```text
attendance_tracker_<project_name>/
├── attendance_checker.py
├── Helpers/
│   ├── assets.csv
│   └── config.json
└── reports/
    └── reports.log
```

## Files Included

* `setup_project.sh` – Main deployment and automation script
* `README.md` – Project documentation

## How to Run

Make the script executable:

```bash
chmod +x setup_project.sh
```

Run the script:

```bash
./setup_project.sh
```

Enter a project name when prompted.

## Updating Attendance Thresholds

During execution, the script asks whether you would like to update the attendance thresholds.

If you choose `yes`, enter new values for:

* Warning threshold
* Failure threshold

The script uses the `sed` command to update the values in `config.json`.

## Environment Validation (Health Check)

Before completing the setup, the script performs a health check:

1. Verifies whether Python3 is installed using:

```bash
python3 --version
```

2. Validates that the required project structure and files exist.

The script then displays a success or warning message.

## Signal Handling and Archive Creation

The script uses the `trap` command to catch the `SIGINT` signal generated by pressing `Ctrl+C`.

If interrupted:

1. An archive named `attendance_tracker_<project_name>_archive.tar.gz` is created.
2. The incomplete project directory is removed.
3. A confirmation message is displayed.

## Testing the Archive Feature

1. Run the script:

```bash
./setup_project.sh
```

2. Enter a project name.
3. When prompted to test interruption, press:

```text
Ctrl + C
```

4. Verify that:

   * The archive file was created.
   * The project directory was removed.

## Technologies Used

* Bash Shell Scripting
* Linux Commands (`mkdir`, `read`, `sed`, `tar`, `trap`)
